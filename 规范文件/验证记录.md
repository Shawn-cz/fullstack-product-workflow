- **未执行 `docker build` / `docker compose up`**：当前测试宿主机未安装 Docker Desktop，因此本轮直接验证了预编译产物 `dist/` + `dist-server/index.mjs` 在 Node 20 下的真实运行与 HTTP 响应，但容器层构建仍需在装有 Docker 的机器或 CI 环境实测一次。
