# 软件产品设计与全栈交付工作流

版本：0.8.0｜日期：2026-11-16｜状态：已完成针对“零开发经验团队”的专项审计升级与 Skill 封装，可进入实际项目试点。

面向**完全没有开发工作经验**、希望每位成员成长为全栈产品设计师并借助 AI 完成软件需求、设计、实现验证与持续改进的团队。每位成员按同一完整流程推进自己的任务，不按专业岗位划分阶段；通过**团队默认黄金技术栈（STD-ARC-09）**统一技术底座，通过**Git 快照救生（STD-CODE-11）**防止改坏代码，通过**黑盒可观察验真法与高风险独立复核门禁（STD-QA-12）**解决“新手看不懂底层代码却要验收 AI 产物”的核心痛点。

当前内容：10 个阶段、112 条规则、13 份模板（含 `templates/` 独立单文件拆分）、贯穿案例（含 Prisma/Zod 机器契约与 T07/T12 黑盒证据格式范本）、Antigravity 原生 Skill（`.agents/skills/fullstack-product-delivery/`），以及 46 组来源登记。

## 从这里开始

1. **在 Antigravity 中使用**：确保项目根目录包含 `.agents/` 与 `AGENTS.md`，直接对 AI 说“按团队全栈工作流推进任务：[你的需求]”。
2. **理解主线与裁剪**：先读 [主流程](00_主流程.md) 的“全栈执行方式、裁剪和完成状态”；负责人明确指令型需求按 `STD-REQ-01` 直接登记 `DEC` 进入 S2，不卡外部用户访谈。
3. **按阶段按需取用单文件模板**：从 [templates/](templates/) 复制当前阶段对应的单个模板（如 `T01`），不要一次填完所有模板。
4. **遵循黄金技术栈与黑盒验真**：新建项目默认采用 Vue 3 + TypeScript + Tailwind + Element Plus/Naive UI + Node.js (Hono/Fastify) + Prisma + SQLite/PostgreSQL（移动端 uni-app/Capacitor）；验收按 [工程质量基线](06_工程质量与审计验收基线.md) 第 6.1 节执行黑盒观察，高风险节点执行独立审计会话复核或团队负责人确认。

## 第一轮试点怎么判断有效

选择一个真实、范围较小的内部工具或业务功能，让试点成员在 Antigravity 中直接触发本工作流 Skill，沿用团队默认黄金技术栈推进到可运行闭环。成员按照 AI 输出的黑盒验真清单（浏览器渲染、双无痕窗口越权测试、Network 状态码、`npx prisma studio` 查库）亲自核验并填写 T07/T12，涉及权限与发布交由负责人或独立审计会话复核。记录完成耗时、返工原因与文档负担，建立团队真实基线。
