# 变更日志

## 0.8.0 — 2026-11-16

- **专项审计与面向“零开发经验团队”的全面补强**：完成对 0.7.0 的全量形式与业务落地审计（见 `审计报告_v0.8.md`），针对零代码背景成员的 6 项落地断层完成闭环升级。
- **新增 3 条核心工程护栏规则，微调 2 条规则（总计 112 条规则、13 份模板、46 组来源）**：
  - 新增 `STD-ARC-09`（固化**团队默认黄金技术栈**：Web 前端 Vue 3 + TypeScript + Vite + Tailwind CSS + Element Plus/Naive UI + Pinia；后端 Node.js + Hono/Fastify + TypeScript + Zod + Prisma + SQLite/PostgreSQL；移动端 uni-app Vue 3 或 Capacitor；终结零经验成员各自随意选型导致无法维护的风险）。
  - 新增 `STD-CODE-11`（**零开发经验成员本地环境与 Git 快照救生**：要求 AI 代管开工前 Git 保存点、小闭环快照、单行启动/测试/查库命令与改坏一键回退）。
  - 新增 `STD-QA-12`（**零代码经验黑盒可观察验真法与高风险独立复核门禁**：将技术验收转化为浏览器渲染、双无痕窗口越权测试、F12 Network 状态码、`npx prisma studio` 可视化查库及单行命令输出；涉及 D0/D1 权限资金、数据迁移 `STD-DAT-04` 或 `S8` 发布必须经独立上下文 AI 交叉审计或团队负责人签字）。
  - 修订 `STD-REQ-01` 与 `S1`：区分“探索型需求”与“指令/契约型需求”，团队负责人明确下达的指令凭 `DEC` 直入 `S2`，免除形式化外部用户访谈阻塞。
  - 修订 `STD-VUE-01` 与 `STD-MOB-01`：与团队黄金技术栈对齐。
- **补齐贯穿案例“最后一公里”样本**：在 `03_贯穿案例_工单.md` 中新增 Prisma Schema + Zod 机器契约代码范本，以及 `T07` 黑盒可观察验真记录、`T12` 验收矩阵与证据索引的完整填写格式范本。
- **封装 Antigravity 原生 Skill 并拆分独立模板**：
  - 新增 `.agents/skills/fullstack-product-delivery/SKILL.md`、`references/stage-routing.md` 及根目录 `AGENTS.md`，支持在 AI IDE 中一键自动按阶段触发。
  - 将 `02_模板包.md` 拆分为 `规范文件/templates/T01~T13` 共 13 个轻量单文件（1–7KB/个），大幅降低单次上下文消耗。
  - 消除原压缩包双层同名目录嵌套，并将历史基线压缩包（含新增的 `v0.7.0-baseline.zip`）与旧审计报告物理隔离至 `历史归档_勿喂给AI/` 目录。
