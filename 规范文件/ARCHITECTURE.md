# 工作流体系结构

版本：1.0.0（正式试点版）。本项目包含可跨平台使用的 Markdown 规范包、黄金栈一键脚手架（`starter/`）、双索引树（`INDEX_TREE.md` + `build-index-tree.mjs`）、前后端同构契约与 RBAC 权限底座（`contracts/`）、双向闭环 CI 四道硬门禁（`ci/`），以及面向 Antigravity 等 AI IDE 的原生 `.agents/skills/fullstack-product-delivery/` 技能与根目录 `AGENTS.md` 规则入口。

## 信息分层

| 层 | 文件 / 目录 | 权威职责 |
|---|---|---|
| 自动触发入口 | `AGENTS.md`、`.agents/skills/fullstack-product-delivery/` | 在 AI IDE 中自动识别工作流纪律、双索引树首读、一键脚手架、安全红线与阶段路由 |
| 导航与索引 | `开始使用.md`、`README.md`、`规范文件/README.md`、`规范文件/INDEX_TREE.md` | 团队启动入口、119 条规则行号切片导航树与 GitHub 一键口令 |
| 流程 | `规范文件/00_主流程.md` | 全栈执行顺序、ATDD 四步闭环、三级裁剪、指令型需求豁免、完成条件 |
| 规则 | `规范文件/01_规则库.md` | 119 条有效唯一规则 ID（`STD-*`）、触发条件、强制动作与验证要求 |
| 工程资产基线 | `规范文件/starter/`、`规范文件/contracts/`、`规范文件/ci/` | 一键脚手架与种子工厂、同构契约与 RBAC 权限基线、自动索引树与双向闭环 CI 门禁 |
| 产物结构 | `规范文件/02_模板包.md` 及 `规范文件/templates/T01~T13` | 按阶段记录实际项目成果的轻量单文件结构 |
| 案例参考 | `规范文件/03_贯穿案例_工单.md` | 展示需求 `AC`、PostgreSQL Prisma、React/Preline 组件、`@req/@ac` 测试与指纹证据格式 |
| AI 执行 | `规范文件/04_AI项目执行说明.md` | AI 执行闭环、Git 快照救生、CI 门禁与黑盒验真步骤的方式 |
| 演进 | `规范文件/05_来源与更新机制.md` | 50 组外部来源登记、候选修订、发布与迁移 |
| 质量应用 | `规范文件/06_工程质量与审计验收基线.md` | Git 救生、契约与载荷指纹、黑盒验真、ATDD 与 CI 硬门禁、三重指纹防过期 |
| 推进应用 | `规范文件/07_项目推进与多agent执行.md` | 增量、依赖、并行开发与独立上下文交叉审计子 agent 说明 |
| 平台应用 | `规范文件/08_移动App专项.md` | 移动端双模式（模式 A：既有 App 修改与对接；模式 B：条件调用从 0 新建 App） |
| 维护 | `CHANGELOG`、`session_handoff`、`验证记录`、`审计报告_v0.9` | 当前版本变更、恢复上下文与真实检查结果 |
| 历史归档 | `历史归档_勿喂给AI/` | 物理隔离历史版本基线 zip（0.5–0.8）、manifest、diff 及旧审计报告，避免污染 AI 上下文 |

实际项目成果使用 REQ/AC/RULE/API/UI/TASK/TEST/EVD 等项目 ID；本工作流规则使用 STD 前缀，来源使用 SRC，模板使用 T。

## 渐进式上下文加载（Progressive Disclosure）设计

1. **常驻轻量规则（< 4KB）**：根目录 `AGENTS.md` 与 `SKILL.md` 仅声明核心纪律、黄金技术栈与阶段路由表。
2. **按阶段单模板加载（1–9KB）**：进入某阶段时，仅从 `规范文件/templates/` 读取对应的单个模板文件。
3. **工程资产按需复制**：S4 复制 `规范文件/contracts/`，S6 复制 `规范文件/ci/`。
4. **历史归档物理隔离**：历史 baseline 压缩包与旧审计报告隔离于 `历史归档_勿喂给AI/`，`.gitignore` 默认排除，不进入日常项目仓库。

## 维护约束

规则新增或修改 → 同步检查相关阶段、汇总模板 `02_模板包.md`、独立模板 `templates/T*.md`、契约与门禁脚本、Skill 路由表、案例与来源 → 记录语义变化 → 运行链接、计数与脚本校验。删除或替换规则时保留弃用与替代说明，不复用旧编号表示不同含义。
