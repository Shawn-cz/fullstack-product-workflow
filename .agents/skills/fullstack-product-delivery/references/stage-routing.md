## 1. 任务路径三级裁剪与移动端双模式

| 路径 | 适用场景 | 必选阶段与最小模板 | 免除内容 |
|---|---|---|---|
| **小变更路径** | 文案、低风险局部样式、单点明确小修 | `S0` + `S5/S7`：在 [T01](../../../../规范文件/templates/T01_项目启动与裁剪卡.md) 简记范围，按 [T06](../../../../规范文件/templates/T06_交互与组件规格.md) 对照既有视觉基线，实际渲染定向检查 | 免写完整蓝图 T03、状态机 T04、ADR、MVP 排期 |
| **功能路径** | 已有系统内新增功能、修改业务规则或修复逻辑缺陷 | `S0` → `S2(REQ/AC)` → `S3` → `S4/S5` → `S6(测试先行RED)` → `S7(实现GREEN+门禁+指纹)` | 免重画全系统架构、免外部探索访谈（指令型需求） |
| **完整路径** | 新产品从 0 到 1、跨模块重构、条件新建移动 App | `S0`–`S9` 全流程贯通；采用 React + Preline UI + PostgreSQL 黄金栈（`STD-ARC-09`）；移动端按 [T13](../../../../规范文件/templates/T13_移动App项目补充卡.md) 与 [08_移动App专项.md](../../../../规范文件/08_移动App专项.md) 判定模式 A/B | 远期未进入本轮迭代的功能不提前细化 |
